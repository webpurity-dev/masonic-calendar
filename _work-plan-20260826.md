## Configuration Strategy

Replace the unused `combine_officers` configuration with a nested `ui_preferences.officer_display` configuration:

```yaml
officer_display:
  not_appointed_label: "Not appointed"
  hide_officer_with_name: "Ignore"
```

`hide_officer_with_name` is matched against the complete trimmed officer name, case-insensitively. Matching officer rows are excluded before model construction, column balancing, and display-row counting.

## Files Affected

- `document/master_v1.yaml` - define the two officer display settings and remove the unused combination rules.
- `src/MasonicCalendar.Core/Loaders/DocumentLayoutLoader.cs` - add the nested officer display configuration model.
- `src/MasonicCalendar.Console/Program.cs` - apply the loaded officer display settings to `UnitModelBuilder`.
- `src/MasonicCalendar.Core/Renderers/Utilities/UnitModelBuilder.cs` - omit officers whose name exactly matches the configured sentinel.
- `src/MasonicCalendar.Tests/UnitModelBuilderRowCountTests.cs` - verify hidden officers are excluded from model output and row counts while partial name matches remain visible.

## Scope

This applies to unit officer rendering through `UnitModelBuilder`. It does not alter source CSV data, list-officer sections, templates, members, or other person types.

## Approach

1. Deserialize `officer_display` under `ui_preferences`.
2. Set the configured vacant label and hidden-name sentinel during application startup.
3. Apply exact sentinel filtering before existing vacant-officer filtering.
4. Validate with focused unit tests.
5. Render Craft unit 137 and confirm `Craft 0137 Off 016` and the sentinel name are absent from the generated unit HTML.

## Risks

- Substring matching could hide legitimate names; exact matching avoids this.
- Filtering after row counting would distort pagination; the shared pre-render filter avoids this.
- Static configuration can leak between tests; tests will restore the previous value.

## Rollback Strategy

Revert the five scoped implementation/configuration edits. Source CSV values are not modified.
