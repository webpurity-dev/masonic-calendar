# Cover Printing Notes - `-cover-as-pages`

Notes to be supplied to the printer with the three-page cover PDF generated by
`-cover-as-pages`.

## Current Version
**2.4.6.5**

## Purpose
This file is a cover component set, not a single cover spread. It contains the
outer front cover, outer back cover, and spine as three separate portrait pages
for the printer to trim, assemble, and bind.

## Page Order
The pages appear in this order in the supplied PDF:

| PDF page | Component | Artwork / treatment |
|---:|---|---|
| 1 | Outer front cover (OFC) | `cover-img-yellow.jpg` |
| 2 | Outer back cover (OBC) | `cover-img-back.jpg` |
| 3 | Spine | Centred 20 mm spine panel with vertical text |

Do not impose these pages as a booklet. Please confirm the required production
imposition with the printer before printing.

## Dimensions
Each supplied PDF page is **111 x 154 mm** portrait. This includes 3 mm bleed on
each edge around the finished A6 trim.

| Component | Supplied page | Finished trim | Bleed |
|---|---:|---:|---:|
| Outer front cover | 111 x 154 mm | 105 x 148 mm | 3 mm on each edge |
| Outer back cover | 111 x 154 mm | 105 x 148 mm | 3 mm on each edge |
| Spine panel | On a 111 x 154 mm page | 20 x 148 mm | Artwork runs to the page height |

The front and back cover images fill their supplied pages and extend through
the bleed. The spine is centred horizontally on its supplied page, leaving
approximately 45.5 mm of background on either side before trimming and
assembly.

## Spine
| Setting | Value |
|---|---|
| Finished width | 20 mm |
| Finished height | 148 mm |
| Text | Dorset Masonic Calendar 2026 |
| Text orientation | Vertical, reading from bottom to top |
| Text size | 16 pt, bold |
| Text margin | 5 mm |
| Text colour | Black |

The spine artwork is centred on the page. Trim the spine to the configured
20 x 148 mm panel, allowing for the printer's binding and finishing process.

## Crop Marks and Bleed Proofing

Generate the printer PDF with:

```powershell
dotnet run -- -template master_v1 -output pdf -cover-as-pages -showprint
```

Crop-mark settings:

- Finished trim reference: 105 x 148 mm A6
- Crop-mark length: 5 mm
- Corner gap: 3 mm
- Stroke: 0.15 px
- Colour: black

For a proof that also shows the bleed boundary:

```powershell
dotnet run -- -template master_v1 -output pdf -cover-as-pages -showbleed -showprint
```

**Important:** the black crop marks on the spine page identify the 105 x 148 mm
A6 reference box used by the renderer. They do **not** identify the 20 mm spine
trim. Do not trim the spine page to those A6 crop marks; use the centred spine
panel and the agreed binding allowance.

## Printing Instructions

- Print at 100% or Actual Size; do not scale the supplied PDF.
- Preserve page size, portrait orientation, backgrounds, images, and spine text.
- Do not add printer margins, headers, footers, automatic rotation, or booklet
	imposition unless agreed with the printer.
- Keep the front and back covers as separate components for cover assembly.
- Confirm the required spine allowance, paper stock, lamination, and PUR or
	other binding method before production.
- Request a physical or calibrated contract proof before the final run.

## Preflight Checklist

- Confirm the PDF contains exactly three pages in the order OFC, OBC, SPINE.
- Confirm each supplied page measures 111 x 154 mm.
- Confirm the front and back covers trim to 105 x 148 mm.
- Confirm the spine panel is centred and trims to 20 x 148 mm, subject to the
	printer's binding allowance.
- Confirm all cover artwork extends through the 3 mm bleed without white edges.
- Confirm the spine text is vertical, legible, and centred within the panel.
- Confirm the printer will not scale, crop, rotate, or impose the supplied PDF.
